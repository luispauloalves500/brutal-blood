BRUTAL BLOOD 0.21.0 — COMO JOGAR / PUBLICAR

JOGAR A VERSAO COMPILADA
1. Extraia todo o ZIP.
2. Tenha Node.js 22 ou superior instalado.
3. Windows: abra INICIAR.bat.
4. Linux/macOS: npm run play
   (desenvolvimento: npm run dev)

Nao abra dist/index.html diretamente por file://.

EDITAR
npm ci
npm run dev

TESTAR
npm test
npm run typecheck

BUILD
npm run build
O build final fica em dist/.

GITHUB PAGES
O projeto inclui .github/workflows/pages.yml.
No repositorio, configure Settings > Pages > Source como GitHub Actions.
